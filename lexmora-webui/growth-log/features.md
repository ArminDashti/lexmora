# Features

- Login against Lexmora API (JWT in localStorage)
- Transform operations UI (including compare)
- History table with sort and detail modal
- Editable AI instruction prompts
- Usage stats by period
- OpenRouter / settings and clear-data actions
- Installable PWA (app-shell precache; `/api/*` network-only)
- Docker production image (Vue build → nginx) with `/api` reverse proxy
- YAML-only local and remote Docker deploy under `.armin/docker-scripts/`
